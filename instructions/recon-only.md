# 任務指示：僅限資產收集（Recon Only）

> 用法：`uv run strix --target <目標> --instruction-file ./instructions/recon-only.md --scan-mode quick --max-budget 1`
>
> 授權前提：目標為客戶書面委託或自有資產。本任務**只做被動／輕度主動偵察**，不進行漏洞利用。

---

## 任務目標

只收集以下三類資產，**不做任何漏洞測試、不發送攻擊 payload、不嘗試登入或繞過**：

1. **子網域**（含解析結果與來源）
2. **來源主機 IP**（真實 IP，需剔除 CDN／WAF 網段）
3. **端點 / URL**（含 HTTP 狀態碼與方法）

---

## 執行限制（重要）

| 限制 | 說明 |
|---|---|
| 不做利用 | 禁止 SQLi／XSS／SSRF／IDOR 等測試，禁止任何注入 payload |
| 不做暴力破解 | 禁止目錄爆破、密碼猜測、帳號枚舉 |
| 請求頻率 | 每目標每秒不超過 5 個請求；`httpx/nuclei` 使用 `-rate-limit 5` |
| 不繞過防護 | 遇到 WAF 攔截即記錄並跳過，不嘗試繞過 |
| 只讀被動來源 | 子網域優先使用被動來源（憑證透明度、被動 DNS） |

---

## 排除規則（輸出前必須套用）

### 1. IP 黑名單：剔除 CDN／雲端代理網段

若解析出的 IP 落在以下網段，**不列入「來源主機 IP」清單**（但可在附註標記為 CDN）：

```
# Cloudflare
104.16.0.0/13        # 104.16.* ~ 104.27.*
172.64.0.0/13        # 172.64.* ~ 172.71.*
2606:4700::/32

# AWS CloudFront
13.32.0.0/15         # 13.32.* ~ 13.35.*
13.224.0.0/14        # 13.224.* ~ 13.227.*
18.65.0.0/16         # 18.65.*
99.84.0.0/15         # 99.84.* ~ 99.85.*
52.84.0.0/15         # 52.84.* ~ 52.85.*
54.230.0.0/16        # 54.230.*
2600:9000::/28
```

> 若目標全站都在 CDN 後方，請另外標記「歷史 DNS／憑證 SAN／子網域 CNAME 指向」作為真實來源線索。

### 2. WAF 與垃圾 URL 剔除

以下字串出現在 URL、參數或標題中即剔除：

```
_Incapsula_Resource
incident_id
CWUDNSAI
xinfo
%7B%7B
```

另外剔除：
- 含 `*` 的通配符 URL
- 重複的 WAF 攔截頁（相同回應長度＋相同標題）

### 3. 狀態碼放寬

**保留**：`200, 301, 302, 400, 401, 403, 405`
（`403/401` 代表端點存在但需授權，屬有價值資產）

**剔除**：`404, 410, 500, 502, 503, 504` 等

### 4. 靜態資源剔除

副檔名符合以下即剔除：

```
.jpg .jpeg .png .gif .svg .ico .webp
.css .js .map
.woff .woff2 .ttf .eot
.mp4 .webm .pdf .zip
```

> 例外：若 `.js` 檔名含 `api`、`config`、`env`、`auth` 等關鍵字，可保留於附錄（供後續分析）。

### 5. 精修：剔除純商品頁

剔除僅以 `/products/` 或 `/categories/` 結尾的展示型頁面。

**例外（需保留）**：路徑中含以下關鍵字
```
api, member, user, admin, account, order, cart, checkout,
login, auth, upload, export, download, internal, debug
```

---

## 輸出格式

請產生三份清單（Markdown 表格 + JSON 檔），並在最後給一段摘要。

### 清單 1：子網域

| 子網域 | 解析 IP | 來源（CT／被動 DNS／CNAME） | CDN 標記 |
|---|---|---|---|

### 清單 2：來源主機 IP

| IP | 對應主機 | 開放埠 | 服務／指紋 | 是否 CDN |
|---|---|---|---|---|

> 僅列出**非 CDN 網段**的 IP；CDN IP 另放附錄。

### 清單 3：端點 / URL

| URL | 方法 | 狀態碼 | 標題 | 備註 |
|---|---|---|---|---|

### 附錄

- 被剔除的 CDN IP 清單（附網段名稱）
- 被剔除的靜態資源統計（數量）
- 被剔除的 WAF／垃圾 URL（範例 3–5 筆即可）
- 未涵蓋範圍與原因

## 建議工具（依環境選用）

| 目的 | 工具 |
|---|---|
| 子網域（被動） | `subfinder`、憑證透明度（crt.sh） |
| DNS 解析與 CNAME | `dnsx`、`dig` |
| HTTP 探測與指紋 | `httpx`（`-sc -title -td -favicon`） |
| URL 收集 | `katana`、`gau`、`waybackurls` |
| 埠掃描（輕量） | `naabu -top-ports 100` |

請將原始輸出存到 `engagements/<客戶代號>/recon/`，並在報告中附上指令與時間。

---

## 報告撰寫要求

- 使用繁體中文（工具名稱、參數、URL 保留原文）
- 每一步附上「執行指令 + 執行時間 + 產出筆數」
- 明確標示哪些資產被排除、用哪條規則排除
- 最後給「下一步建議」：哪些端點值得進一步測試（只列清單，不執行）
