## 先決條件

- Docker（需正在執行）
- 任一[支援的供應商](/llm-providers/overview)的 LLM API 金鑰（OpenAI、Anthropic、Google 等）

## 安裝

<Tabs>
  <Tab title="curl">
    ```bash
    curl -sSL https://strix.ai/install | bash
    ```
  </Tab>
  <Tab title="pipx">
    ```bash
    pipx install strix-agent
    ```
  </Tab>
</Tabs>

## 設定

設定你的 LLM 供應商。建議透過 [Vercel AI Gateway](/llm-providers/vercel-ai-gateway) 或 [OpenRouter](/llm-providers/openrouter) 使用 GLM-5.3：

<CodeGroup>
```bash Vercel AI Gateway
export STRIX_LLM="vercel_ai_gateway/zai/glm-5.3"
export LLM_API_KEY="your-api-key"
```

```bash OpenRouter
export STRIX_LLM="openrouter/z-ai/glm-5.3"
export LLM_API_KEY="your-api-key"
```
</CodeGroup>

<Tip>
為取得最佳效果，請使用 `zai/glm-5.3`、`deepseek/deepseek-v4.1-flash-1017`、`anthropic/claude-opus-5-5`（需具備 [CVP](https://support.claude.com/en/articles/14604842-cyber-verification-program) 存取權），或 `openai/gpt-6.1-sol`（需具備 [Daybreak](https://openai.com/daybreak/) 存取權）。
</Tip>

## 執行第一次掃描

```bash
strix --target ./your-app
```

<Note>
第一次執行會自動拉取 Docker 沙箱映像。結果會儲存在 `strix_runs/<run-name>`。
</Note>

## 目標類型

Strix 接受多種目標類型：

```bash
# 本機程式庫
strix --target ./app-directory

# GitHub 儲存庫
strix --target https://github.com/org/repo

# 線上 Web 應用程式
strix --target https://your-app.com

# 多個目標（白箱測試）
strix -t https://github.com/org/repo -t https://your-app.com

# 從檔案讀取目標，每行一個（略過空行與註解行）
strix --target-list ./targets.txt
```
