---
title: "本機 Web 檢視器"
description: "用 strix view 在本機儀表板中檢視一次執行"
---

每次掃描在執行過程中都會把結果寫入磁碟。`strix view` 會把這些檔案以本機儀表板呈現，無論是執行中的掃描或已完成的掃描皆可。

```bash
strix view                                    # 最近一次執行
strix view my-run-name                        # ./strix_runs 下指定的執行
strix view --host 0.0.0.0 --port 8080 --no-open
```

介面已隨 Strix 預先建置好，不需要額外安裝，也不需要 JavaScript 建置步驟。儀表板直接從磁碟讀取執行檔案。所有資料都留在你的機器上，也不需要雲端帳號。

## 選項

<ParamField path="run" type="string">
  `./strix_runs` 下的執行名稱。預設為最近一次執行。
</ParamField>

<ParamField path="--host" type="string" default="127.0.0.1">
  要綁定的主機位址。使用 `0.0.0.0` 可讓其他機器連上檢視器。
</ParamField>

<ParamField path="--port" type="number" default="0">
  要服務的連接埠。預設會自動挑選一個可用的臨時連接埠。
</ParamField>

<ParamField path="--no-open" type="boolean">
  不要自動開啟瀏覽器。
</ParamField>

## 儀表板包含什麼

- **總覽** —— 執行狀態、目標，以及目前為止所有發現的嚴重度分布。
- **漏洞** —— 每個經驗證的發現，含嚴重度、細節與重現步驟。
- **代理關係圖** —— 多代理團隊的即時地圖，以及每個代理正在做什麼。
- **引導（Steering）** —— 對執行中的掃描送出指令，在過程中導引代理。引導功能只在執行中掃描所開啟的儀表板可用；獨立執行的 `strix view` 沒有可引導的即時掃描。
- **歷史** —— 瀏覽本機上的過往執行並切換。請先在儀表板驗證電子郵件，才能解鎖其他執行紀錄。
- **報告** —— 產生可分享的報告並以電子郵件寄送。需先驗證電子郵件。

## 分享連結

<Warning>
  列印出的網址含有權杖，持有即可存取執行資料，也能對執行中的掃描進行引導。請只分享給可信任的使用者。
</Warning>

若要從其他機器連上檢視器，請以 `--host 0.0.0.0` 啟動，並把列印網址中的 `0.0.0.0` 換成可連線的 IP 或主機名稱，再用防火牆限制連接埠。沒有權杖衍生的工作階段，請求就無法讀取執行資料。
