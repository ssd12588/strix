---
title: "掃描模式"
description: "為你的使用情境選擇合適的掃描深度"
---

Strix 提供三種掃描模式，用來平衡速度與徹底程度。

## 快速（quick）

```bash
strix --target ./app --scan-mode quick
```

針對明顯漏洞的快速檢查。最適合：
- CI/CD 流程
- Pull Request 驗證
- 快速煙霧測試

**耗時**：數分鐘

## 標準（standard）

```bash
strix --target ./app --scan-mode standard
```

例行安全檢視的均衡測試。最適合：
- 定期安全評估
- 發行前驗證
- 開發里程碑

**耗時**：30 分鐘至 1 小時

**白箱行為**：使用原始碼感知的測繪與靜態初步篩選，優先找出值得動態驗證的利用路徑。

## 深度（deep）

```bash
strix --target ./app --scan-mode deep
```

徹底的滲透測試。最適合：
- 全面安全稽核
- 正式環境上線前檢視
- 關鍵應用程式評估

**耗時**：依目標複雜度約 1–4 小時

**白箱行為**：先執行大範圍的原始碼感知篩選（`opengrep`、AST 結構搜尋、機密掃描、供應鏈檢查），再系統性地動態驗證最有希望的候選項目。

<Note>
深度模式是預設值。它會探索邊界情況、串接型漏洞與複雜攻擊路徑。
</Note>

## 如何選擇

| 情境 | 建議模式 |
|------|----------|
| 每個 PR | 快速（quick） |
| 每週掃描 | 標準（standard） |
| 重大版本發布前 | 深度（deep） |
| 漏洞賞金獵捕 | 深度（deep） |
