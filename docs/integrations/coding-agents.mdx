Strix 天生適合由 AI 程式開發代理驅動。安裝官方代理技能後，你的代理就知道如何執行滲透測試、修補發現，並把 Strix 接進 CI。

## 安裝技能

支援任何遵循開放 [SKILL.md 標準](https://agentskills.io) 的代理 —— Claude Code、Cursor、Codex、Gemini CLI、OpenCode 等數十種：

```bash
npx skills add usestrix/strix
```

| 技能 | 你的代理會學到什麼 |
|-------|------------------------|
| `penetration-testing-with-strix` | 對程式碼、URL、網域或 IP 執行無介面掃描 —— 自架 CLI 或受管雲端皆可 —— 支援預算上限，並讀取結果 |
| `managed-pentesting-with-strix` | 透過 REST 操作受管的 [app.strix.ai](https://app.strix.ai) 平台 —— 不需要本機 Docker 或 LLM 金鑰 |
| `fix-security-vulnerabilities-with-strix` | 分類發現、修正根本原因，並重跑 Strix 驗證每項修正 |
| `ci-security-scanning-with-strix` | 把 PR 安全掃描加入 GitHub Actions 或任何 CI（自架 CLI 或受管平台） |
| `application-security-testing` | 評估整個產品：為每個資產選擇合適的測試，再把發現整理成一份修補計畫 |
| `web-app-penetration-testing` | 對線上 Web 應用或測試站做黑箱滲透測試 —— 範圍、帳號密碼與多帳號存取控制測試 |
| `api-security-testing` | 依 OWASP API Security Top 10 測試 REST/GraphQL API —— 以結構描述驅動的列舉、BOLA/IDOR、授權 |
| `owasp-top-10-testing` | 系統性 OWASP Top 10 評估，並誠實說明各類別的涵蓋程度 |
| `find-security-vulnerabilities-in-code` | 對儲存庫或工作目錄做白箱安全檢視，並以利用程式確認發現 |

可用 `npx skills add usestrix/strix --skill penetration-testing-with-strix` 只安裝單一技能，或不安裝直接使用：

```bash
npx skills use usestrix/strix@penetration-testing-with-strix | claude
```

## 兩種執行方式 —— 自架或受管

兩者使用相同引擎，產生的驗證結果與 SARIF 也相同，代理可依情況選擇或混用：

- **開源 CLI（自架）** —— 在你的 Docker 沙箱中本機執行，使用自己的 LLM 金鑰。免費、完全本機、可離線（air-gap）。最適合本機開發迴圈與完整掌控。
- **受管雲端** —— 在 Strix 的基礎設施上執行。可用 `strix cloud` CLI（每個 REST 操作都有對應的 `strix cloud <resource> <verb>` 指令）或直接使用 [app.strix.ai REST API](https://docs.app.strix.ai)。不需要 Docker、不需要 LLM 金鑰；另外提供團隊儀表板、排程、PR 審查與可下載的 PDF/DOCX 報告（企業方案）。最適合沙箱／CI 環境與團隊使用。以 `strix cloud login` 登入（瀏覽器裝置登入，首次使用時建立帳號），或在儀表板的 **Settings → API Access** 建立權杖。`managed-pentesting-with-strix` 技能包含完整流程。

## 易於代理操作的介面

代理所需的一切都是機器可讀的：

- **無介面 CLI** —— `strix -n` 不開啟 TUI 直接執行，結束碼為 `0`（正常）、`1`（錯誤）、`2`（發現漏洞）。
- **雲端 CLI** —— 當 stdout 不是終端機（或加上 `--json`）時，`strix cloud` 會輸出 JSON，沒有 TTY 時絕不互動提示，結束碼為 `0`（成功）、`1`（錯誤）、`2`（用法錯誤）、`4`（需要驗證）、`5`（需要付款）。點數加值可透過代理錢包完成 Stripe 機器付款驗證（`strix cloud billing topup --credits N --yes`）。帳號設定也能用 CLI 完成：`strix cloud workspaces list|create|use`、`strix cloud org members invite`、`strix cloud billing subscribe`、`strix cloud billing portal`、`strix cloud integrations install github`。最後三個會印出託管連結，由使用者開啟以完成付款或核准安裝。
- **REST API** —— 受管平台在 `https://app.strix.ai/api/v1` 提供有文件的 [OpenAPI](https://docs.app.strix.ai/openapi.json)（掃描、漏洞、資產、PR 審查、排程、webhook），支援 bearer 權杖與 scopes。
- **結構化結果** —— 每次執行都會在 `strix_runs/<run-name>/` 下寫出 `vulnerabilities.json`、`vulnerabilities.csv`、`findings.sarif`（SARIF 2.1.0）與每項發現的 Markdown；雲端提供相同內容的 JSON 以及 SARIF 匯出。
- **預算控制** —— `--max-budget` 與 `--max-turns` 可為代理設定硬性的成本／時間上限。
- **`AGENTS.md`** —— [儲存庫的代理指南](https://github.com/usestrix/strix/blob/main/AGENTS.md)，含快速參考。
- **`llms.txt`** —— 本文件已索引於 [docs.strix.ai/llms.txt](https://docs.strix.ai/llms.txt)，完整匯出於 [docs.strix.ai/llms-full.txt](https://docs.strix.ai/llms-full.txt)；每個頁面也可在網址後加上 `.md` 取得 Markdown 版本。

## 提示詞範例

技能安裝好之後，這類提示詞就能直接運作：

```text
用 Strix 對這個 repo 做滲透測試（快速模式，預算 $10），並摘要發現。
```

```text
修正上一次 Strix 執行中所有重大與高風險發現，然後重新掃描驗證。
```

```text
把 Strix 安全掃描加進我們的 GitHub Actions，讓每個 PR 都被測試。
```
