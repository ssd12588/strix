## 設定

```bash
export STRIX_LLM="azure/your-gpt6-deployment"
export AZURE_API_KEY="your-azure-api-key"
export AZURE_API_BASE="https://your-resource.openai.azure.com"
export AZURE_API_VERSION="2025-11-01-preview"
```

## 設定項

| 變數 | 說明 |
|----------|-------------|
| `STRIX_LLM` | `azure/<你的部署名稱>` |
| `AZURE_API_KEY` | 你的 Azure OpenAI API 金鑰 |
| `AZURE_API_BASE` | 你的 Azure OpenAI 端點網址 |
| `AZURE_API_VERSION` | API 版本（例如 `2025-11-01-preview`） |

## 範例

```bash
export STRIX_LLM="azure/gpt-6.1-sol-deployment"
export AZURE_API_KEY="abc123..."
export AZURE_API_BASE="https://mycompany.openai.azure.com"
export AZURE_API_VERSION="2025-11-01-preview"
```

## 先決條件

1. 建立 Azure OpenAI 資源
2. 部署模型（例如 GPT-6.1 Sol）
3. 從 Azure 入口網站取得端點網址與 API 金鑰

<Note>
使用 OpenAI 模型進行安全測試需要 [Daybreak](https://openai.com/daybreak/) 存取權，在 Azure 上亦然。
</Note>
