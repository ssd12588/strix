## 設定

```bash
export STRIX_LLM="openai/gpt-6.1-sol"
export LLM_API_KEY="sk-..."
```

## 可用模型

| 模型 | 說明 |
|-------|-------------|
| `openai/gpt-6.1-sol` | 代理式安全工作在能力與成本間的最佳平衡 |
| `openai/gpt-6-astra` | 旗艦款，最大能力 |
| `openai/gpt-6-luna` | 快速且便宜 |

完整清單請見 [OpenAI 模型文件](https://platform.openai.com/docs/models)。

<Note>
使用 OpenAI 模型進行安全測試需要 [Daybreak](https://openai.com/daybreak/)（Trusted Access for Cyber）。沒有它，模型會拒絕大多數攻擊性任務。[申請存取](https://openai.com/form/enterprise-trusted-access-for-cyber/)。
</Note>

## 取得 API 金鑰

1. 前往 [platform.openai.com](https://platform.openai.com)
2. 進入 API Keys
3. 建立新的密鑰

## 自訂 Base URL

適用於相容 OpenAI 的 API：

```bash
export STRIX_LLM="openai/gpt-6.1-sol"
export LLM_API_KEY="your-key"
export LLM_API_BASE="https://your-proxy.com/v1"
```
