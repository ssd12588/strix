[Novita AI](https://novita.ai) 透過相容 OpenAI 的 API 提供快速、具成本效益的開源模型推論。

## 設定

```bash
export STRIX_LLM="openai/zai-org/glm-5.3"
export LLM_API_KEY="your-novita-api-key"
export LLM_API_BASE="https://api.novita.ai/openai"
```

## 可用模型

| 模型 | 設定 |
|-------|---------------|
| GLM-5.3 | `openai/zai-org/glm-5.3` |
| Kimi K3.1 Pro | `openai/moonshotai/kimi-k3.1-pro` |
| Kimi K3 | `openai/moonshotai/kimi-k3` |
| DeepSeek V4.1 Flash | `openai/deepseek/deepseek-v4.1-flash-1017` |
| DeepSeek V4 Pro | `openai/deepseek/deepseek-v4-pro` |
| MiniMax M3.1 Flash | `openai/minimax/minimax-m3.1-flash` |
| GLM-5.3 Flash | `openai/zai-org/glm-5.3-flash` |

## 取得 API 金鑰

1. 在 [novita.ai](https://novita.ai) 註冊
2. 在儀表板進入 **API Keys**
3. 建立新金鑰並複製

## 優勢

- **成本效益** —— 具競爭力的價格，依 token 計費
- **相容 OpenAI** —— 透過 `LLM_API_BASE` 即可直接替換使用
- **大上下文** —— 模型支援最高 262k token 的上下文視窗
- **函式呼叫** —— 表列模型皆支援工具／函式呼叫
