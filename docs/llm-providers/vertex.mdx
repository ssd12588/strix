## 設定

```bash
export STRIX_LLM="vertex_ai/gemini-4-argon"
```

不需要 API 金鑰 —— 會使用 Google Cloud 應用程式預設憑證（ADC）。

## 驗證方式

### 選項 1：gcloud CLI

```bash
gcloud auth application-default login
```

### 選項 2：服務帳戶

```bash
export GOOGLE_APPLICATION_CREDENTIALS="/path/to/service-account.json"
```

## 可用模型

| 模型 | 說明 |
|-------|-------------|
| `vertex_ai/gemini-4-argon` | 安全測試的整體最佳表現 |
| `vertex_ai/gemini-3.8-flash` | 更快且更便宜 |

<Note>
使用 Gemini 進行安全測試需要 [Fairwind 計畫](https://deepmind.google/fairwind-program/)。沒有它，網路安全防護機制會阻擋大多數攻擊性任務。
</Note>

## 專案設定

```bash
export VERTEXAI_PROJECT="your-project-id"
export VERTEXAI_LOCATION="global"
```

## 先決條件

1. 在 Google Cloud 專案中啟用 Vertex AI API
2. 確認你的帳號具有 `Vertex AI User` 角色
