## 設定

```bash
export STRIX_LLM="anthropic/claude-sonnet-5-5"
export LLM_API_KEY="sk-ant-..."
```

## 可用模型

| 模型 | 說明 |
|-------|-------------|
| `anthropic/claude-sonnet-5-5` | 智慧與速度的最佳平衡 |
| `anthropic/claude-opus-5-5` | 深度分析的最大能力 |

<Note>
使用 Claude 進行安全測試需要[網路安全驗證計畫](https://support.claude.com/en/articles/14604842-cyber-verification-program)（CVP）。沒有它，安全分類器會阻擋大多數攻擊性任務。Red Team Access 涵蓋已授權的滲透測試。
</Note>
