[OpenRouter](https://openrouter.ai) 透過單一 API 提供來自多個供應商的 100 多種模型。

## 設定

```bash
export STRIX_LLM="openrouter/z-ai/glm-5.3"
export LLM_API_KEY="sk-or-..."
```

## 可用模型

使用 `openrouter/<provider>/<model>` 格式即可存取 OpenRouter 上的任何模型：

| 模型 | 設定 |
|-------|---------------|
| GLM-5.3（建議） | `openrouter/z-ai/glm-5.3` |
| GPT-6.1 Sol | `openrouter/openai/gpt-6.1-sol` |
| GPT-6 Astra | `openrouter/openai/gpt-6-astra` |
| Claude Opus 5.5 | `openrouter/anthropic/claude-opus-5.5` |
| Claude Sonnet 5.5 | `openrouter/anthropic/claude-sonnet-5.5` |
| Gemini 4 Argon | `openrouter/google/gemini-4-argon` |
| Gemini 3.8 Flash | `openrouter/google/gemini-3.8-flash` |
| DeepSeek V4.1 Flash | `openrouter/deepseek/deepseek-v4.1-flash-1017` |
| DeepSeek V4 Pro | `openrouter/deepseek/deepseek-v4-pro` |
| Kimi K3.1 Pro | `openrouter/moonshotai/kimi-k3.1-pro` |
| GLM-5.3 Flash | `openrouter/z-ai/glm-5.3-flash` |

OpenAI、Anthropic 與 Gemini 模型在 OpenRouter 上仍保留各供應商的安全防護。以它們進行安全測試需要 [Daybreak](https://openai.com/daybreak/)、[CVP](https://support.claude.com/en/articles/14604842-cyber-verification-program) 或 [Fairwind](https://deepmind.google/fairwind-program/) 存取權。

## 取得 API 金鑰

1. 前往 [openrouter.ai](https://openrouter.ai)
2. 登入並進入 Keys
3. 建立新的 API 金鑰

## 優勢

- **單一 API** —— 可存取 OpenAI、Anthropic、Google、Meta 等供應商的模型
- **備援路由** —— 供應商之間自動容錯切換
- **成本追蹤** —— 監控所有模型的使用量
- **更高的速率上限** —— OpenRouter 會代你處理供應商限制
