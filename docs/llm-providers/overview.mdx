Strix 透過 [LiteLLM](https://docs.litellm.ai/docs/providers) 支援 100 多種 LLM 供應商。

## 設定

設定你的模型與 API 金鑰：

| 模型                 | 供應商                  | 設定                    |
| --------------------- | ------------------------- | -------------------------------- |
| GLM-5.3（建議） | Vercel AI Gateway         | `vercel_ai_gateway/zai/glm-5.3`  |
| GLM-5.3（建議） | OpenRouter                | `openrouter/z-ai/glm-5.3`        |
| GPT-6.1 Sol           | OpenAI                    | `openai/gpt-6.1-sol`             |
| Claude Opus 5.5       | Anthropic                 | `anthropic/claude-opus-5-5`      |
| Claude Sonnet 5.5     | Anthropic                 | `anthropic/claude-sonnet-5-5`    |
| Gemini 4 Argon        | Google Vertex             | `vertex_ai/gemini-4-argon`       |
| DeepSeek V4.1 Flash   | DeepSeek                  | `deepseek/deepseek-flash`        |
| DeepSeek V4 Pro       | DeepSeek                  | `deepseek/deepseek-v4-pro`       |
| Kimi K3.1 Pro         | Moonshot                  | `moonshot/kimi-k3.1-pro`         |

<Note>
頂尖的 OpenAI、Anthropic 與 Gemini 模型需要網路安全存取計畫才能進行安全測試：OpenAI 需 [Daybreak](https://openai.com/daybreak/)，Anthropic 需[網路安全驗證計畫](https://support.claude.com/en/articles/14604842-cyber-verification-program)，Gemini 需 [Fairwind 計畫](https://deepmind.google/fairwind-program/)。
</Note>

<CodeGroup>
```bash Vercel AI Gateway
export STRIX_LLM="vercel_ai_gateway/zai/glm-5.3"
export LLM_API_KEY="your-api-key"
```

```bash OpenRouter
export STRIX_LLM="openrouter/z-ai/glm-5.3"
export LLM_API_KEY="your-api-key"
```
</CodeGroup>

## 本機模型

用 [Ollama](https://ollama.com)、[LM Studio](https://lmstudio.ai)，或任何相容 OpenAI 的伺服器在本機執行模型：

```bash
export STRIX_LLM="ollama/llama4"
export LLM_API_BASE="http://localhost:11434"
```

設定步驟與建議模型請見[本機模型指南](/llm-providers/local)。

## 模型格式

使用 LiteLLM 的 `provider/model-name` 格式：

```
openrouter/z-ai/glm-5.3
openai/gpt-6.1-sol
anthropic/claude-sonnet-5-5
vertex_ai/gemini-4-argon
bedrock/us.anthropic.claude-sonnet-5-5
ollama/llama4
```
