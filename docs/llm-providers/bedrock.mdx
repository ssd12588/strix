## 設定

```bash
export STRIX_LLM="bedrock/us.anthropic.claude-sonnet-5-5"
```

不需要 API 金鑰 —— 會使用環境中的 AWS 憑證。

## 驗證方式

### 選項 1：AWS CLI 設定檔

```bash
export AWS_PROFILE="your-profile"
export AWS_REGION="us-east-1"
```

### 選項 2：存取金鑰

```bash
export AWS_ACCESS_KEY_ID="AKIA..."
export AWS_SECRET_ACCESS_KEY="..."
export AWS_REGION="us-east-1"
```

### 選項 3：IAM 角色（EC2/ECS）

會自動使用執行個體角色的憑證。

## 可用模型

| 模型 | 說明 |
|-------|-------------|
| `bedrock/us.anthropic.claude-sonnet-5-5` | Claude Sonnet 5.5 |
| `bedrock/us.anthropic.claude-opus-5-5` | Claude Opus 5.5 |
| `bedrock/us.anthropic.claude-haiku-5-5` | Claude Haiku 5.5 |

<Note>
使用 Claude 進行安全測試需要[網路安全驗證計畫](https://support.claude.com/en/articles/14604842-cyber-verification-program)（CVP），在 Bedrock 上亦然。
</Note>

## 先決條件

1. 在 AWS Bedrock 主控台啟用模型存取
2. 確認你的 IAM 角色／使用者具有 `bedrock:InvokeModel` 權限
