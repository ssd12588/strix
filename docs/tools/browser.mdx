---

Strix 透過 Playwright 使用無頭 Chrome 瀏覽器，像真實使用者一樣與 Web 應用程式互動。

## 運作方式

所有瀏覽器流量都會自動經過 Caido 代理，讓 Strix 能完整掌握每個請求與回應。這可用於：

- 測試用戶端漏洞（XSS、DOM 操作）
- 走訪認證流程（登入、OAuth、MFA）
- 觸發大量依賴 JavaScript 的功能
- 擷取動態產生的請求

## 能力

| 動作     | 說明                                 |
| ---------- | ------------------------------------------- |
| 瀏覽   | 前往網址、跟隨連結、處理重新導向  |
| 點擊      | 操作按鈕、連結、表單元素 |
| 輸入       | 填寫表單、搜尋框、輸入欄位   |
| 執行 JS | 在頁面內容中執行自訂 JavaScript   |
| 截圖 | 擷取視覺狀態用於報告            |
| 多分頁  | 在多個瀏覽器分頁間測試           |

## 範例流程

1. 代理啟動瀏覽器並前往登入頁
2. 填入帳號密碼並送出表單
3. 代理擷取認證請求
4. 代理前往受保護的區域
5. 以修改過的 ID 重送請求，測試是否存在 IDOR
