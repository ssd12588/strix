---
title: "沙箱工具"
description: "Strix 容器內預先安裝的安全工具"
---

Strix 執行於以 Kali Linux 為基礎的 Docker 容器中，並預先安裝了完整的安全工具。代理可透過[終端機](/tools/terminal)使用其中任何工具。

## 偵察

| 工具                                                       | 說明                            |
| ---------------------------------------------------------- | -------------------------------------- |
| [Subfinder](https://github.com/projectdiscovery/subfinder) | 子網域探索                    |
| [Naabu](https://github.com/projectdiscovery/naabu)         | 快速連接埠掃描器                      |
| [httpx](https://github.com/projectdiscovery/httpx)         | HTTP 探測與分析              |
| [Katana](https://github.com/projectdiscovery/katana)       | Web 爬取與網站偵察             |
| [ffuf](https://github.com/ffuf/ffuf)                       | 快速 Web 模糊測試器                        |
| [Nmap](https://nmap.org)                                   | 網路掃描與服務偵測 |

## Web 測試

| 工具                                                   | 說明                      |
| ------------------------------------------------------ | -------------------------------- |
| [Arjun](https://github.com/s0md3v/Arjun)               | HTTP 參數探索         |
| [Dirsearch](https://github.com/maurosoria/dirsearch)   | 目錄與檔案暴力猜解 |
| [wafw00f](https://github.com/EnableSecurity/wafw00f)   | WAF 指紋辨識               |
| [GoSpider](https://github.com/jaeles-project/gospider) | 用於擷取連結的 Web 爬蟲   |
