Strix 代理使用專門的工具，像真正的滲透測試人員一樣測試你的應用程式。

## 核心工具

<CardGroup cols={2}>
  <Card title="瀏覽器" icon="globe" href="/tools/browser">
    以 Playwright 驅動的 Chrome，用於操作 Web 介面。
  </Card>
  <Card title="HTTP 代理" icon="network-wired" href="/tools/proxy">
    以 Caido 驅動的代理，用於攔截與重送請求。
  </Card>
  <Card title="終端機" icon="terminal" href="/tools/terminal">
    Bash shell，用於執行指令與安全工具。
  </Card>
  <Card title="沙箱工具" icon="toolbox" href="/tools/sandbox">
    預先安裝的安全工具：Nuclei、ffuf 等。
  </Card>
</CardGroup>

## 其他工具

| 工具           | 用途                                  |
| -------------- | ---------------------------------------- |
| Python 執行環境 | 撰寫並執行自訂利用腳本 |
| 檔案編輯器    | 讀取與修改原始碼              |
| 網頁搜尋     | 以 Exa 或 Perplexity 取得即時 OSINT   |
| 筆記          | 掃描過程中記錄發現        |
| 報告      | 產生含 PoC 的漏洞報告 |
