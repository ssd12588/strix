---
title: "終端機"
description: "用於執行指令與安全工具的 Bash shell"
---

Strix 可在 Docker 沙箱內使用常駐的 bash 終端機，因此代理能存取所有[預先安裝的安全工具](/tools/sandbox)。

## 能力

| 特性           | 說明                                                |
| ----------------- | ---------------------------------------------------------- |
| 狀態保留  | 工作目錄與環境變數會在指令之間保留 |
| 多個工作階段 | 可同時執行多個終端機以並行作業           |
| 背景作業   | 啟動長時間執行的程序而不阻塞              |
| 互動式       | 可回應提示並控制執行中的程序           |

## 常見用途

### 執行安全工具

```bash
# 子網域列舉
subfinder -d example.com

# 漏洞掃描
nuclei -u https://example.com

# SQL 注入測試
sqlmap -u "https://example.com/page?id=1"
```

### 程式碼分析

```bash
# 快速 SAST 篩選
opengrep scan --config /opt/opengrep-rules ./src

# 結構化 AST 搜尋
sg scan ./src

# 機密偵測
gitleaks detect --source ./
trufflehog filesystem ./

# 供應鏈與錯誤設定檢查
trivy fs ./
```

### 自訂腳本

```bash
# 執行 Python 利用程式
python3 exploit.py

# 執行 shell 腳本
./test_auth_bypass.sh
```

## 工作階段管理

代理可以同時執行多個終端機工作階段，例如：

- 主要工作階段負責主要測試
- 次要工作階段負責監控
- 背景程序用於伺服器或監看程式
