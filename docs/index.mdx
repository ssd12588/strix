Strix 是一群自主運作的 AI 代理，行為就像真正的駭客 —— 它們會動態執行程式碼、找出漏洞，並用概念驗證（PoC）確認漏洞真的可利用。它為需要快速、準確安全測試的開發者與安全團隊而打造，免去人工滲透測試的沉重負擔，也沒有靜態分析工具常見的誤報。

## 適用場景

- **應用程式安全測試** —— 偵測並驗證應用程式中的重大漏洞
- **快速滲透測試** —— 幾小時內完成滲透測試，而非幾週
- **Bug Bounty 自動化** —— 自動化研究並產生 PoC，加快回報速度
- **CI/CD 整合** —— 在上線前攔下漏洞

## 核心能力

- **完整駭客工具箱** —— 瀏覽器自動化、HTTP 代理、終端機、Python 執行環境
- **真實驗證** —— 產出可運作的 PoC，而不是誤報
- **多代理協同** —— 專責代理在複雜目標上合作
- **開發者優先的 CLI** —— 互動式 TUI 或適合自動化的無介面模式

## 安全工具

Strix 代理配備完整的工具箱：

| 工具 | 用途 |
|------|------|
| HTTP 代理 | 完整操作與分析請求／回應 |
| 瀏覽器自動化 | 多分頁瀏覽器，用於 XSS、CSRF、認證流程測試 |
| 終端機 | 互動式 shell，用於執行指令 |
| Python 執行環境 | 自訂利用程式開發與驗證 |
| 偵察 | 自動化 OSINT 與攻擊面測繪 |
| 程式碼分析 | 靜態與動態分析能力 |

## 漏洞涵蓋範圍

| 類別 | 範例 |
|------|------|
| 存取控制 | IDOR、權限提升、認證繞過 |
| 注入 | SQL、NoSQL、指令注入 |
| 伺服器端 | SSRF、XXE、反序列化 |
| 用戶端 | XSS、原型污染、DOM 漏洞 |
| 業務邏輯 | 競態條件、流程竄改 |
| 認證 | JWT 漏洞、工作階段管理 |
| 基礎設施 | 錯誤設定、曝露的服務 |

## 多代理架構

Strix 使用專責代理組成的關係圖來進行全面的安全測試：

- **分散式流程** —— 針對不同攻擊與資產的專責代理
- **可擴展測試** —— 平行執行，快速且全面地涵蓋
- **動態協調** —— 代理會合作並共享發現

## 快速範例

<CodeGroup>
```bash Vercel AI Gateway
# 安裝
curl -sSL https://strix.ai/install | bash

# 設定
export STRIX_LLM="vercel_ai_gateway/zai/glm-5.3"
export LLM_API_KEY="your-api-key"

# 掃描
strix --target ./your-app
```

```bash OpenRouter
# 安裝
curl -sSL https://strix.ai/install | bash

# 設定
export STRIX_LLM="openrouter/z-ai/glm-5.3"
export LLM_API_KEY="your-api-key"

# 掃描
strix --target ./your-app
```
</CodeGroup>
